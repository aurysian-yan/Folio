# 字体库、存放位置与云同步

## Shared library

主字体库由 `folio-sync::unified_library` 合并本机目录和有效云目录，再交给
`folio-query` 搜索、排序、筛选、分页与计数。macOS、Windows/Linux、iOS、Android
复用这一结果；收藏、最近访问、手动收藏夹和智慧收藏夹使用同一查询索引。
云端页保留文件、任务、冲突和最近删除管理。

同内容关联以文件指纹和字款修订标识为依据，不依据显示名称。同名字体的不同
版本分别保留；TTC 成员使用真实字族标识和成员索引，一个集合文件只传输一次。
完整云元数据参与既有属性筛选；旧记录不足时保留可下载文件条目，不猜测属性，
不计入已识别字族数。本机已有同内容缓存可补齐元数据，不重复上传对象。

## Location states

| 常驻位置 | 本机可读取副本 | 有效云记录 | 操作 |
| --- | --- | --- | --- |
| 本机与云端 | 有 | 有 | 预览、查看全部位置；有 Folio 托管副本时可移除 |
| 仅在云端 | 无 | 有 | 详情、收藏、加入收藏夹、下载到本机 |
| 本机 · 待上传 | Folio 托管且允许上传 | 无 | 上传、仅在本机保留 |
| 本机 · 未加入云同步 | 被排除，或系统、安装、引用来源 | 无 | 预览、查看位置；有现有导入能力的平台可建立托管副本 |

位置标识不随隐藏字体信息偏好隐藏。安装／激活状态与传输行独立展示。
共享接口返回每字款的位置与字族的本机／总字款数，不由客户端重新推断位置。
部分字款可用时显示「部分在本机 · 2/6 字款」，切换字款后显示准确位置；
默认优先预览本机可用字款。打开云端详情不会下载文件。

工具栏的存放位置筛选独立于来源、安装和激活筛选。这是设备浏览条件，不写入
跨设备智慧收藏夹规则。安装／激活筛选只匹配真实本机来源。

桌面详情列出全部副本、来源类别、完整路径、定位入口和当前预览副本。移动端
显示「本机 · Folio 字体库」与文件名，不新增系统安装能力。
云端确认时间表示上次目录读取结果；离线仍可浏览缓存目录和本机预览。

## Synchronization and policies

新旧连接默认按需下载，已有本机文件保留。「自动同步」控制目录与变更同步；
「自动下载云端字体」单独控制全量下载，默认关闭。

先接收并持久保存目录与用户信息，再处理字体文件。失败文件不阻止目录条目
进入字体库。下载请求按指纹合并，通过内容和解析校验并进入本机目录后才标记
可用；失败与取消保留独立任务状态，提供单文件重试。

主动下载将单文件偏好设为本机保留；移除本机下载将其设为云端保留。后续同步
和全量自动下载均尊重云端保留偏好。移除只处理 Folio 管理的副本，其他安装和
引用副本继续使字体保持本机可用。

托管文件默认参与上传。排除偏好保存在独立文件策略表，重启、缓存重建和同一
来源内容更新后仍保留。恢复参与上传会清除该来源的排除。已发布的云端副本
不会因暂停上传而删除，位置继续按实际副本显示。系统、安装、引用文件不自动
上传；macOS 可复用已有复制导入入口建立托管副本。

「从云字体库删除」移入最近删除；同步后移除各设备同内容的 Folio 托管副本，
系统安装与外部引用保留。恢复只恢复云记录，本机下载另行触发。

数据库从版本 9 增量迁移至 11，保留连接、字体、收藏与既有云端保留偏好。
文件策略不依赖可重建的解析缓存。切换连接清除旧云归属和任务，但保留设备
文件偏好，本机文件继续可用。

## Platform presentation

| 平台 | 本机来源 | 界面约定 |
| --- | --- | --- |
| macOS | 托管、引用、用户安装、系统、进程激活 | SwiftUI；定位到全部副本，复用复制导入能力 |
| Windows/Linux | 托管、引用、用户安装、系统 | 共用 Tauri、React 与 HeroUI；位置独立于来源筛选 |
| iOS/Android | 应用托管库 | 沿用 React Native、Expo 和原生控件；原「本地」入口改为「字体库」 |

Hero 保留 [Figma 桌面内容结构](https://www.figma.com/design/nCaYeYhwKuWx2gDYf8hq2u/Folio?node-id=8-7166)：
标题、字族统计或问题说明、云同步说明。移动端仅参考布局。字族统计与同步文件
计数分开；仅云端保留显示正常可下载状态，不描述为云端领先或本机落后。
没有检测数据时不填写示例中的更新数量或剩余配额。
