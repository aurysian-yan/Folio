# 各平台字体分类与同步状态

## 存放位置

同步分类以有效字体文件的内容指纹为单位，与字族、字款及安装状态分开统计。相同文件的副本只计一次；一个字族中的不同字体文件分别计数。云端状态表示上次成功读取的同步记录，不能用于推断尚未读取的服务器变更。

| 分类 | 本机副本 | 已发布云端记录 | 含义与入口 |
| --- | --- | --- | --- |
| 已同步到本机 | 存在 | 存在，未删除 | 本机可预览，也可移除本机副本而保留云端 |
| 仅在云端 | 不存在或主动保留在云端 | 存在，未删除 | 可下载；仅保留云端不等于有待下载任务 |
| 仅在本地未同步 | 位于 `ManagedFonts` 且可用 | 没有已发布记录 | 首次同步前、自动同步关闭、导入后及上传失败时均可存在 |
| 本地系统或引用字体 | 位于系统、用户安装目录或外部引用目录 | 不要求存在 | 没有加入托管库时，不计入待上传数量 |
| 最近删除 | 不作为活动副本统计 | 删除记录存在 | 只进入最近删除与恢复流程，不计入云字体库活动数量 |

`cloudOnly` 是云端记录的本机可用性结果，同时涵盖主动保留云端和本机文件丢失；不能只看 `localPath` 是否非空。文件丢失后，路径字符串可能仍在数据库中。未发布的 `FontAdded` 记录也不能证明云端已有该文件。

Rust 的 `font_sync_summary` 统一提供 `syncedCount`、`cloudOnlyCount` 和 `localOnlyFingerprints`，由各端库快照传递。仅本地指纹读取现有有效文件缓存，不重新解析字体；排除损坏文件、系统与引用目录、云端保留和删除记录。该读取不修改连接、同步策略或字体文件。

## 平台边界

| 平台 | 本地来源与状态 | 云端分类 | 主页面统计 |
| --- | --- | --- | --- |
| macOS | 托管、引用、用户安装、系统；另保留进程激活与不可用状态 | 共享 Rust 云端记录；本机可用与仅云端分别显示 | 本机目录按字族统计；云端条目作为独立文件条目，不能加到本机字族数中 |
| Windows | 托管、引用、用户安装、系统与不可用；已激活范围按现有来源规则判断 | 与 Linux 共用 Tauri 接口和 React 页面 | 本机目录字族统计，上传与下载按文件指纹统计 |
| Linux | 沿用本平台字体目录和现有来源规则 | 与 Windows 相同 | 与 Windows 相同 |
| iOS | 应用内托管库；不套用桌面安装或激活分类 | 共享 Rust 记录，通过 Swift 桥传递 | 本机字族统计；未下载的云端文件不混入本地查询结果 |
| Android | 应用内托管库；不套用系统字体安装分类 | 共享 Rust 记录，通过 Kotlin 桥传递 | 与 iOS 相同 |

安装、激活、收藏、最近访问、字形类型、健康与存放位置是不同维度。例如已安装字体可以同时有托管副本和云端记录；收藏和最近访问记录也可在字体仅保留云端时继续存在。各端不新增与原有平台能力不符的安装入口。

## 传输与连接状态

| 状态 | 判断依据 | 与存放位置的关系 |
| --- | --- | --- |
| 未连接 | 成功读取后确认没有配置 | 不等于读取失败；本地字体仍可使用 |
| 读取中或读取失败 | 原生状态读取结果 | 不能用过期云端记录提示差异或声称已同步 |
| 上传、下载中 | 当前运行状态及未完成队列 | 文件可已有另一端副本，例如重传或重新下载 |
| 有待处理任务 | 去重后的未完成队列或真实仅本地指纹 | 完成队列不重复计数；首次同步前也能识别本地未同步 |
| 同步失败或取消 | 实际同步结果 | 保留真实位置，不能推断上传或下载已经完成 |
| 有同步冲突 | 未处理冲突记录 | 字体冲突和收藏夹冲突分别处理 |
| 已同步 | 成功完成，无本地未同步、待下载或冲突 | 仅云端保留另外提示，不宣称所有文件都已下载到本机 |

同一台设备可以同时有仅本地与仅云端字体。此时同步说明同时列出两侧数量，不用单向“领先”覆盖另一侧差异。

## 主页面 Hero

使用 [Figma 桌面组件](https://www.figma.com/design/nCaYeYhwKuWx2gDYf8hq2u/Folio?node-id=8-7166) 的内容结构：标题、统计或问题说明、云同步说明；冲突和容量状态再补一行本地统计。移动端只参考布局，标题和状态文案复用桌面语言键。

七种状态按损坏、字体冲突、容量不足、可用更新、云端可下载、本地未同步、正常的顺序选择。健康问题优先，但同步说明独立保留实际连接和传输状态。仅云端字体使用“可下载”，只有真实下载任务使用“待下载”，不将用户保留云端的旧字体称为“新字体”。

React 与 React Native 共用 `shared/library-hero.ts`；macOS 使用同一套语言键与判断顺序。macOS 和 Windows/Linux 保留已有字体健康入口；移动端尚无独立健康页，健康标题保持信息展示，云端和设置入口可操作。

已有 `recentCount` 是最近访问记录，故仍显示“最近访问”，不冒充设计示例中的“最近加入”。更新数量与 WebDAV 剩余配额只接受真实检测结果；没有数据时不填入设计示例数字。文件数量也不能与字族数量直接相减来估算未同步数量。
