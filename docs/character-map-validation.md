## 实现范围

- 页面继承当前字款、来源与轴值。Windows/Linux 使用同一 React/HeroUI 三栏布局、侧栏拖动与折叠、OverlayScrollbars；macOS 复用 NavigationSplitView 与 inspector，移除 sheet。字体检查器与字符渲染共享字款、来源和轴值。Android、iOS/iPadOS 使用现有 FontNavigation 与共享 RN 页面。
- 实际编码 Unicode 单字符按码点升序排列。内部按每批 256 项加载，界面连续滚动自动追加，不显示页码或手动翻页按钮；支持单字符或 `U+XXXX` 精确搜索、脚本筛选、轴值调整、放大查看及复制字符/码位。多个码点映射到同一 Glyph ID 时仍保留各条目。
- 桌面与宽屏 iPad 使用网格加并排详情区；手机在网格下显示详情。移动标题栏固定显示字族名与字符数两级标题，控件置于列表滚动头部，复用 PageHeader、SettingsGroup、DetailSlider 与平台选择菜单；Android 复用原有玻璃菜单，并支持长列表滚动。页面关闭保留父级字体库与详情状态；桌面进入时展开两栏，返回恢复原有侧栏状态。
- 网格只挂载可见及邻近内容；Rust 图片 LRU 缓存预算为 32 MiB，估算包含传输字符串与解码像素。关闭释放句柄与对应缓存，解析/渲染不持有字体库锁，客户端丢弃过期请求结果。
- 新文案登记在根目录 `locales/`。单色字形使用当前主题前景色，彩色字形保留原色和透明度；空白字符保留元数据，不借用其他字体。

未编码字形、连字、ZWJ/变体序列、WOFF/WOFF2、Unicode 名称检索、调色板编辑和字形导出不在范围内。

## 共享接口

`folio-core::CharacterMapIndex` 只解析字体字节与 collection face index，不依赖平台 API。`folio-render::CharacterMapService` 管理只读快照与 PNG 渲染；UniFFI、Tauri 和 Expo 传递同一 camelCase JSON 契约，TypeScript 定义位于 `shared/character-map.ts`。

| 操作 | 输入 | 输出 |
| --- | --- | --- |
| `openCharacterMap` | `faceId`、`revisionId`、`sourcePath` | `handle`、revision、来源、face index、字符数及脚本统计 |
| `queryCharacterMap` | `handle`、`text`、`script`、`offset`、`limit` | 有序 `entries`（`codepoint`、`glyphId`、`script`）、总数及 offset；默认 limit 256，上限 1024 |
| `renderCharacterMap` | `handle`、`glyphIds`、`axes`、`size`、`foreground` RGBA | 按请求顺序返回 PNG data URL，状态为 `ready`、`empty` 或 `error` |
| `closeCharacterMap` | `handle` | 释放会话；重复关闭安全 |

打开必须使用目录中登记的来源和 revision，完整文件 hash 核验后绑定快照。后续请求检查文件可读性、大小、修改和创建时间，拒绝检测到的删除/替换，不重新选择来源。时间及大小均被刻意保留的原地篡改不做逐请求完整 hash；打开时始终完整校验。请求退出后，正在执行的渲染在字形边界检查关闭状态。

错误键区分未下载、来源不可读、版本变化、字体损坏、输入无效、轴值无效、会话关闭和渲染失败；无匹配字符返回空页。单字形损坏只返回该项错误，失败图片不缓存，可单独重试。云端未下载时复用各端已有下载入口。

渲染固定使用 Vello CPU `0.3.0`、resvg `0.48.1`、image `0.25.10`。SVG 禁用系统字体与文件/网络路径解析，仅允许字体内嵌资源；支持 SVGZ、当前前景色和首个 CPAL 调色板变量。字体文件上限 512 MiB，单次渲染最多 256 字形、图片边长 16–1024；内嵌资源限制编码/解压大小、像素尺寸及总资源预算。

## 自动选择与可变轴刷新（2026-10-17）

- macOS、Windows/Linux、Android、iOS/iPadOS 的浏览设置增加「自动选择首个非空字符」，默认开启，复用共享中英文文案及各端现有偏好存储。按码点顺序以真实渲染结果跳过空白和单字形错误；必要时分批跨页查找，手动选择、切换查询及退出会取消查找。筛选后保留有效选择，否则重新选择；关闭时允许手动查看空白字形。
- 实时轴值与列表提交值分离。拖动只更新选中字符的大预览与网格项；其他字符保留旧图。松手后优先更新可见项目，再按需更新屏幕外项目，不重新打开会话或查询字符索引。React 共用会话渲染队列，macOS 使用对应的原生优先队列，每批最多 16 个字形；连续输入只保留执行中与最新请求。
- 松手后以 180ms 缓出、最多四个真实中间轴值帧过渡到最终值，图片间以 75ms 短暂交接缓和切换；渲染较慢时跳过多余中间帧。再次拖动取消后续批次及过渡，系统减少动态效果时仅绘制最终轴值。选中字符仍保持即时更新。
- Tauri 移除轴值导致的大预览重新挂载，列表不再因渲染请求变化而丢弃旧图。React 两端保留正在解码的中间帧与最新候选图，解码后替换；渲染或解码失败保留成功图片并提供重试，真正的空白结果正常清除图片。会话、查询、字符身份及请求序号隔离迟到结果；分页与自动探测乱序返回不会截断已有条目。严格模式效果重新挂载不再提前释放渲染器。
- Android 原生滑块增加编辑开始、结束和取消事件；iOS 透传系统滑块编辑事件，卸载时结束未完成交互。macOS 系统滑块及 Tauri Claralight 使用原有编辑回调。既有 Android 空白字符冒烟用例改为显式选择 NULL，不再依赖进入时自动选择空白字符。
