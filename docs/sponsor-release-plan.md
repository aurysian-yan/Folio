# Official Release Sponsorship Plan

规划日期：2026-10-17。状态：**待实施**。本文确定官方分发版的功能边界与验收要求，
不表示当前 Release 已有赞助校验。执行顺序见 [路线图](../FOLIO_ROADMAP.md)，
同步设计见 [多端同步架构](sync-architecture.md)。

2026-10-18 调整：官方高级版解锁采用云服务器在线验证，替代离线导入永久凭证。
服务器处理激活、权益查询与授权续验；字体文件仍由本地、WebDAV 或 LAN 传输。

## 1. Distribution Policy

- 官方 Release 的基础字体管理和单 WebDAV 同步免费，赞助解锁进阶工作流。
- 全部功能源码保留在仓库，自行编译默认全部开放，包括优化后的 release 构建；
  不要求赞助凭证、官方账号、官方签名或联网激活。
- 沿用仓库现有 `AGPL-3.0-only`，不把进阶实现改成私有模块，也不以赞助规则改写
  现有源码许可证。在线授权仅控制官方构建中的高级功能入口与执行策略。
- 不限制本地字体数、收藏夹数、字体格式、基础预览或导出数量，不收取同步流量费，
  不提供强制使用的 Folio 云存储。
- 不追溯锁定已交付的基础能力。新功能达到验收门槛后才可出现在解锁权益中。

## 3. Entitlement Model

### 3.1 Online Activation and Validation

- 保留一次赞助、已授予功能长期有效的权益政策，不改为订阅。客户端使用有期限的
  授权租约，租约到期表示需要在线续验，不表示需要再次赞助。价格与赞助渠道另定。
- 首期使用激活码，无需先建设完整账号或支付系统。人工核对赞助后，在服务器登记
  权益并发放激活码；客户端首次解锁必须通过 HTTPS 请求服务器确认，不能仅凭本地
  文件或标志解锁。人工发放不替代在线验证服务。
- 同一授权可用于赞助者自己的多平台设备，不设置设备数量上限。参与受限同步的
  官方客户端各自激活和续验；自行编译的设备不请求官方授权服务。
- 客户端激活后获得独立的续验凭据与服务器签名租约，保存到平台安全存储；
  启动、回到前台及启动高级任务时检查租约，在续验窗口内发起在线刷新。
  有效租约可直接使用，不为每次字体操作发起请求；超时与失败按退避策略重试。
- 租约包含授权编号、安装实例绑定、产品、能力 ID、格式版本、签发时间、续验时间、
  最终有效截止时间、密钥编号与签名。实例标识随机生成，不采集硬件指纹；订单、
  邮箱、WebDAV 账号、字体清单和本地路径不得进入租约或验证请求。
- 断网、超时或服务故障时，已激活客户端可在租约有效期及其包含的离线宽限期内
  继续使用。超过最终截止时间且无法续验时，仅暂停受限的新任务，提示联网验证；
  未激活设备不能以网络故障为由放行。宽限期不无限续延，本地验签只校验缓存租约。
- 续验周期、宽限时长及服务长期停运时的权益保障在 S0 固定，进入 S1 前形成明确
  发布契约。时间判断以服务器时间及本机可信时间记录为依据，覆盖时钟回拨和重启，
  不允许修改系统时间无限延长租约。
- 服务器明确返回撤销或无效授权时停止授予高级能力；网络失败、限流与服务器错误
  单独处理，不能误判为撤销。正常永久权益不会因租约过期从服务器记录中删除；
  重新验证后恢复。补发激活码不要求重新赞助。

### 3.2 Cloud Validation Service

| 请求／操作 | 服务器职责 | 客户端行为 |
| --- | --- | --- |
| 激活 | 校验激活码和权益状态，建立安装实例，签发续验凭据与租约 | 安全保存凭据，更新统一能力状态 |
| 权益查询／续验 | 认证续验凭据，读取最新权益与撤销状态，返回新签名租约或明确拒绝结果 | 原子替换租约；临时故障使用仍有效的缓存并重试 |
| 发放／补发／撤销 | 经管理端认证后登记或调整授权，保留可追溯记录 | 补发后重新激活；撤销最迟在续验或缓存租约最终到期时生效 |

- 部署独立的云端 HTTPS 验证服务及权益数据库，保存授权、能力集合、状态和最小
  安装实例记录；激活与续验需支持幂等处理，避免重复请求产生重复授权或丢失凭据。
  激活码与续验凭据不明文落库、不写日志；管理接口与公开验证接口分离并鉴权。
- 私钥只保存在服务器受保护的密钥环境；应用只携带验签公钥。私钥不进入源码、
  安装包、日志或普通构建产物，轮换时覆盖仍有效租约与旧客户端的兼容路径。
- S1 包含 TLS、请求限流、超时、健康监测、脱敏日志、权益数据库备份／恢复与部署
  回滚验收。云厂商、服务器规格和后端实现选型在实施前确定，本轮不新增技术栈。
- 验证服务仅处理高级版授权请求，不托管或中转字体，不读取 WebDAV 凭据，不参与
  LAN 配对、设备组信任或同步合并；基础免费功能无需访问该服务。

### 3.3 Enforcement Boundary

- 定义统一的 `BuildChannel = community | official` 与能力结果
  `FeatureAccess = allowed | sponsor_required | verification_required | invalid_grant`。
  `verification_required` 表示租约已过最终截止时间或缓存不可用且需重新联网验证，
  与服务器明确拒绝的 `invalid_grant` 区分。普通本地构建默认
  `community`；只有官方发布流程显式选择 `official`。不得以 Debug/Release、
  Android 签名或商店身份推断渠道。
- 渠道是构建期常量；UI 只读取能力结果。共享 Rust 应用服务在保存启用配置、
  启动手动／自动任务及恢复持久任务时执行同一策略，UniFFI、Tauri、移动原生服务
  均调用该边界，避免只在按钮上加锁。授权策略不得进入 `folio-core` 或同步合并算法。
- 所有业务实现公开且共用；渠道差异仅为能力策略。不建设混淆、反调试或对抗自行
  编译的机制。官方限制不是同步数据的权限或安全边界。
- 在线验证由共享应用服务协调，原生后台服务复用同一安全存储与授权状态，
  不依赖 React／RN 页面存活；UI 不能自行写入已解锁状态。
- 激活码、续验凭据、租约、授权状态和渠道不写入同步协议，不影响事件签名、字体身份、哈希或冲突结果。
  免费版与自行编译版使用相同的数据格式，互相交换数据无需重新导入。

### 3.4 Data Preservation

- 授权无效、租约超过最终截止时间或缓存损坏且无法续验时，暂停受限的新任务，
  不清空配置、日志、缓存、收藏或待发送事件；
  在当前原子写入完成后停止，已接收的合法事件保留。
- 多端点已配置时允许用户选择一个 WebDAV 继续基础同步，不自动挑选或跨库切换，
  其他端点保留并标为暂停。各端点的进度继续独立保存。
- 冲突查看／解决、本地资料导出和已有同步来源的恢复读取不受限。先前配置的端点
  和配对设备可进入显式恢复模式：只拉取已有资料，不产生新的跨端复制、删除或
  自动任务；恢复数据先进入本地暂存，再由用户确认纳入字体库。
- 自行编译版切回官方版时按相同规则保留数据。重新在线激活或续验成功即可续跑，
  不重置设备身份、不重复发布已交付事件。

## 4. Delivery Plan

| 批次 | 范围 | 依赖 | 完成门槛 |
| --- | --- | --- | --- |
| S0 | 固定能力 ID、免费范围、渠道、在线 API、租约格式、续验／宽限时长及停运保障；记录人工发放／补发／撤销流程 | 本文；现有发布矩阵 | 明确服务器与客户端契约、部署选型及异常策略；不改变现有功能可用性 |
| S1-Server | 部署验证服务与权益数据库，接通激活、查询、续验及管理操作 | S0 | HTTPS 实网请求、幂等／限流、密钥隔离、监测、备份恢复与回滚通过 |
| S1-Client | 共享能力策略、各端激活／续验、安全缓存、离线宽限及状态；公开自行编译说明 | S0；联调依赖 S1-Server；对应平台应用边界 | 官方／社区渠道行为可测；无私钥入包；在线、断网、故障与恢复矩阵通过 |
| S2 | 多 WebDAV 与局域网各自完成后，接入相应权益 | S1 服务端与客户端通过；路线图 P5／P6 独立验收 | 每项权益有真实可用实现及目标平台记录 |
| S3 | 目录监听／热重载接入 `library.watch` | P8 文件监听与修订验收；S1 服务端与客户端通过 | 手动刷新保持免费；离线目录和文件变化不丢用户状态 |

S1 指服务端和客户端共同交付；客户端可先按 S0 契约开发，但不能以模拟服务替代
正式在线联调。S0/S1 可与基础产品和同步开发并行，不阻断 P0–P3 免费基础能力；
在线验证服务是官方高级版上线的前置依赖，完整账号和自动支付系统可后置。任何平台尚未完成的
功能都不得显示为已交付权益；解锁不代表获得该平台尚未实现的字体安装能力。

## 5. Release Gates

- 社区 Debug 与优化 release 构建无需任何秘密或官方服务即可使用全部已实现能力。
- 官方未激活、有效／无效激活码、重复激活、跨平台同授权、续验、补发和撤销均有
  实网覆盖；伪造／篡改／跨实例复制租约、未知签名密钥与损坏缓存不能解锁。
- 覆盖有效租约离线启动、续验窗口、宽限边界、超过最终截止时间、时钟回拨／重启、
  DNS／TLS／超时／429／5xx 及重连恢复。临时故障不误撤销权益，宽限到期不损坏数据。
- 服务部署、密钥轮换、数据库备份恢复与回滚有记录；官方高级版启用前，实际验证
  服务及对应客户端通过联调。免费版与社区版不依赖其可用性。
- 覆盖所有任务入口，包括 UI、UniFFI、Tauri、自动调度、重启续跑和恢复模式；
  执行中的任务失去授权时不破坏事务与已完成传输。
- 跨渠道复用同一用户库、恢复单 WebDAV、重新解锁、重复激活与续验均无数据损失。
- 官方矩阵各原生产物的渠道可验证，签发私钥未打包；自行编译流程不依赖私有仓库。
  移动 JS 与原生／Rust 渠道不一致时发布检查失败。
- 修改发布清单时单独提升清单格式并更新客户端兼容策略，不把激活码或租约塞入现有
  `folio-release.json`。未调整清单前用安装包内的构建元数据校验渠道。
- 新 UI 使用共享语言键并执行 `pnpm i18n:validate`；浅深色、长文本、键盘／读屏
  和移动安全区域纳入对应平台验收。文档规划阶段不新增 UI 或收款入口。
