# 在线字体移动端实施记录

更新：2026-10-22。对应总规划的 M1；M2、D1、D2、D3 继续按总规划执行。

## 当前接入

- Expo 增加「在线字体」入口，覆盖 Android 底栏、iPhone 原生标签栏与 iPad 侧栏。
- 来源共用 Rust 配置与关键词编码，支持新增、编辑、启停、排序和重置内置来源。
- 内置来源包含 Google Fonts、ZeoSeven Fonts、猫啃网、100font 与 Font Library。
  旧配置缺少新内置来源时，会在内置来源段末尾补入，保留用户原有顺序和自定义来源。
- 来源图标从已打开页面的 `icon`／`apple-touch-icon` 声明获取，失败后尝试站点
  `/favicon.ico`。自定义图标从系统文件选择器导入，优先于网站图标，支持切回自动。
  图标和选择均仅保存在本机，不随 WebDAV 同步。
- iOS 使用 WKWebView、Android 使用 WebView。网页不注册应用脚本桥接；网页弹窗
  进入当前内容视图，已知网盘原始 deeplink 交给系统打开。
- 首次使用须确认版权说明。内置浏览器支持地址、搜索、前进、后退、刷新和清除网站数据。
- 网页下载先由用户确认，再交给原生任务；下载凭据与带签名地址不进入任务数据库或同步事件。
- iOS 使用后台 URLSession 与 Keychain；Android 14 及以上使用用户发起的 JobScheduler
  任务，较早版本使用 WorkManager 前台任务与 Keystore。
- 任务支持进度、暂停、重试和取消；下载完成后留待用户选择收录或保存到系统文件。
- Rust 检查内容而非仅依赖扩展名，计算 BLAKE3；ZIP 先验证全部路径和资源限制，再提取
  字体候选。字体内容分析、重复检测、原生预览与收录复用已有服务。
- 来源资料按字体指纹存储。WebDAV v1 追加可选 `source_metadata`，旧 `online_origin`
  继续保留；网站配置、Cookie、浏览历史、账号与临时下载 URL 不进入同步。

## 浏览界面（2026-10-24 调整）

- 顶部固定「起始页」标签，后接启用的来源与临时网页标签；起始页不能关闭。首次进入显示
  起始页，切换时保留原生网页实例、历史和滚动位置。关闭当前页回到最近使用的网页，全部关闭
  后回到起始页。
- 起始页正文使用可编辑仪表盘，个人收藏与最近浏览默认各显示两行。底部标题栏直接作为「搜索或输入网址」入口，
  正文没有第二个搜索框。网页态显示标题与域名，点击同一底栏进入编辑并选中地址。
- 输入时底栏随键盘上移，上方显示网址前往动作或全部启用来源的关键词搜索动作。输入和键盘
  提交不会替用户选择来源；关键词提交只收起键盘，点击来源才执行。有效网址直接前往，缺协议
  时补 HTTPS；取消编辑不改变网页。
- 普通切换已打开来源只恢复原页面。设置中的「切换来源时沿用关键词」默认开启，仅首次打开
  来源时继承最近提交的词。来自起始页或全局搜索的明确搜索请求使用本次关键词，不受开关影响。
  各来源已提交词、起始页草稿、地址编辑与全局搜索分别持有，URL 回填不覆盖编辑草稿。
- 底栏页面工具按上下文提供站内搜索、添加或编辑收藏、收藏夹与历史记录、下载任务和关闭网页。
  站内搜索仍聚焦同一个底栏。起始页不提供收藏自身与关闭操作，临时网页不提供来源专属搜索。
- 收藏包含固定个人收藏、根目录网页和单层自建文件夹，支持编辑、移动、排序和删除。重复地址
  编辑已有收藏。删除文件夹会将内部网页移到根目录；个人收藏不可删除或重命名。
- 历史只记录成功主页面的最终地址，按日期分组，同日相同地址合并；刷新、失败页、下载链接与
  子资源不新增记录。同页地址变化更新当前记录。默认保留 90 天、最多 1,000 条。收藏与历史仅存
  本机，不随 WebDAV 同步；清空历史保留收藏和网站登录状态。
- 打开收藏或历史时优先复用匹配的启用来源，否则打开临时网页；相同目标地址复用标签。
  来源删除或停用不删除收藏或历史，也不会把临时网页自动登记为来源。
- 起始页、页面工具和「设置 > 在线字体」共用下载与收录二级页面。数字角标统计排队和传输任务；
  只有失败、暂停、待处理或待收录任务时显示提示点。关闭网页或关闭面板不取消原生任务，完成后
  不自动收录。来源快照共用；在线页或任务面板可见时才轮询，进入后台停止界面轮询。
- Android 保留现有玻璃底栏折叠、紧凑标题条与背景合成采样。起始页与其他主页共用滚动折叠，网页底边固定停在
  紧凑控件上方，导航展开只覆盖网页。iOS 沿用系统标签栏，iPad 分栏保留搜索与网页实例。
- 来源管理、网站数据、区域提示、站内配色与自定义 CSS 仍位于「设置 > 在线字体」。原有站点主题、
  标题清理、页面加载与失败交互保持；独立全局搜索规格见 `mobile-global-search.md`。

## 区域提示与加载失败（2026-10-23 调整）

- 内置来源中 Google Fonts 与 Font Library 标记为在大陆可能需要额外网络环境。标记按
  `fonts.google.com`、`fontlibrary.org` 域名匹配，支持子域和用户自建的同域名来源，
  不修改 Rust 来源配置，也不参与同步。
- 区域判断使用 Cloudflare 公共 `cdn-cgi/trace`，只解析 `loc` 国家代码；成功结果缓存
  24 小时，失败结果缓存 1 小时后重试。仅在在线字体页激活、已同意版权说明、存在受限
  来源且设置开关开启时请求，4 秒超时，不阻塞页面。
- 「设置 > 在线字体」提供「区域提示」开关，默认开启。关闭后不发起出口查询，也不显示
  预判提示；查询失败或未知时同样不显示预判提示，只保留通用失败文案。判断结果仅存本机，
  不发送字体、账号、浏览记录或连接配置。
- 加载页在来源名称下方显示区域提示；失败页根据来源与判断结果显示区域说明。提示文案
  使用「可能」「部分地区」等不确定表述，不作为访问拦截。
- 整页加载失败改为独立失败页：来源图标、名称、失败地址、具体原因、可选区域说明，
  以及「重试」「更换来源」两个操作。重试重新导航当前地址并恢复加载页；更换来源关闭
  当前标签页，回到最近使用的标签页或来源列表。顶部提示条只保留地址错误、网盘
  deeplink、下载等非整页问题。
- 原生失败细分为离线、无法连接、服务器错误、安全连接失败和通用加载失败；iOS 依据
  `NSURLError` 与主框架 5xx 判断，Android 依据 `WebViewClient` 错误码、连接状态与
  `onReceivedHttpError` 判断。
- 新建来源标签页时，加载页与网页之间同步加入内容模糊与透明度动画：与圆形遮罩同为
  620 毫秒；iOS 使用 `UIVisualEffectView`，Android 12 及以上使用 `RenderEffect`，
  较低版本只保留透明度，减少动态效果时直接显示。站内跳转、刷新和标签页切换直接显示
  网页，不再播放淡入。旧导航和旧主题的异步回调仍不能展示新页面。

## 执行边界

共享 `folio-transfer` 管理任务状态与校验；平台负责系统后台调度和凭据。任务重试增加
generation，旧尝试的进度、完成、失败或系统停止回调不能覆盖新尝试。SQLite revision
用于更新冲突检查；Rust 下载还使用文件资源锁排除同一任务的并行写入。

Android 下载逐跳验证 HTTPS、解析目标地址并固定 DNS，跨源重定向不转发网页凭据。
可用强 ETag 时用 Range 和 If-Range 续传；服务端返回完整内容时重新下载。
iOS 后台会话由系统处理重定向与恢复，应用检查起始和最终 URL，不承诺逐跳 DNS/IP
拦截。暂停或失败时若系统提供恢复数据，重试优先使用该数据。

Android 可处理网页内生成的 `blob:` 下载。Google Fonts 会在沙箱 `srcdoc` 框架中
生成 ZIP，再以 `blob:null/...` 触发下载；这类地址无法由原生传输重放。Android
在页面内安装只转发 `Blob` 对象的中继，确认下载后分块写入应用缓存，再由
`folio-transfer` 校验并转为普通任务。中继不向网页暴露原生接口，只在用户点击
下载时读取页面已创建的对象，不执行站点脚本之外的逻辑。单个 blob 限 512 MiB；
读不到、超过上限或页面已撤销对象时提示下载失败，并清理临时文件。iOS 与桌面端
仍只处理 HTTPS GET 下载；依赖 POST、验证码或特殊客户端的下载须在网页内重新取得
受支持的链接，不重放网页脚本，也不自动尝试破解登录或下载限制。

字体限 512 MiB，ZIP 限 2 GiB；解压总量 2 GiB、单条目 512 MiB、条目数 10,000、
路径深度 16、压缩比 200。拒绝越界路径、特殊文件和加密压缩包，不递归解压嵌套包。
下载完成不自动收录；ZIP 中未选字体不进入字体库。

图标支持 PNG、JPEG、WebP、ICO，统一解码为不超过 128 × 128 的 PNG，移除原始图片
元数据。自定义文件限 8 MiB、4096 × 4096，远端文件限 1 MiB。SVG、HTML 和脚本
不会作为图标执行或保存。远端请求不携带 Cookie，逐跳检查 HTTPS 和解析地址。
成功缓存保留一天，失败请求退避十分钟；自定义图标不受自动刷新覆盖。

## 新标签页与导航偏好

新标签页按区块保存展示顺序、普通／详细／列表样式及折叠行数。默认显示个人收藏和
最近浏览，各两行；自定义网页收藏夹和下载记录可在页面编辑模式中添加。移除区块
不删除内容，展开状态只在当前会话保留。区块通过拖动柄排序，来源设置使用相同的
拖动方式；历史、收藏项和下载任务本身不参与这次排序。

最近浏览默认过滤已知来源首页，可在区块编辑或在线字体设置中开启显示；完整历史
不受过滤影响。详细卡片按网址共享标题、摘要与图片缓存，最多保留一百项，每项
一天内复用结果，最多同时读取三个公开页面；读取失败使用既有名称和来源。
下载进度使用实际字节数，总大小未知时不显示百分比。

底部导航折叠开关位于浏览设置，默认开启，Android 和 iOS 26 及以上在所有主页面
使用滚动折叠，旧版 iOS 保持原有导航。弹窗和仪表盘编辑期间暂停滚动折叠。
网页标题条只出现在在线字体页面，点击后在同一面板编辑地址和使用页面工具。

收藏夹、历史记录与下载共用一个聚合二级页面，各入口直接打开对应页签，原页面保留
在导航栈内。顶部复用统一标题栏，两侧分别为圆形返回和搜索按钮，中间使用与云端
相同的液态玻璃图标分段控件，不显示工具栏标题；轨道高 44 点、图标 20 点，
描边与两侧按钮一致，拨片常态四周保留 4 点。正文滚动至标题栏下方时共用背景采样
与渐进模糊；收藏编辑、文件夹浏览、历史查询、任务操作及字体检查仍在此页面完成。
下载按实际创建时间分组，支持文件名、来源及域名搜索，旧任务缺少时间时不伪造日期。
