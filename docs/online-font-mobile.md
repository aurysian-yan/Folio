# 在线字体移动端实施记录

更新：2026-10-22。对应总规划的 M1；M2、D1、D2、D3 继续按总规划执行。

## 当前接入

- Expo 增加「在线字体」入口，覆盖 Android 底栏、iPhone 原生标签栏与 iPad 侧栏。
- 来源共用 Rust 配置与关键词编码，支持新增、编辑、启停、排序和重置内置来源。
- 来源图标从已打开页面的 `icon`／`apple-touch-icon` 声明获取，失败后尝试站点
  `/favicon.ico`。自定义图标从系统文件选择器导入，优先于网站图标，支持切回自动。
  图标和选择均仅保存在本机，不随 WebDAV 同步。
- iOS 使用 WKWebView、Android 使用 WebView。网页不注册应用脚本桥接；网页弹窗
  进入当前内容视图，已知网盘原始 deeplink 交给系统打开。
- 首次使用须确认版权说明。内置浏览器支持地址、搜索、前进、后退、刷新和清除网站数据。
- 网页下载先由用户确认，再交给原生任务；下载凭据与带签名地址不进入任务数据库或同步事件。
- iOS 使用后台 URLSession 与 Keychain；Android 14 及以上使用用户发起的 JobScheduler
  任务，较早版本使用 WorkManager 前台任务与 Keystore。
- 任务支持进度、暂停、重试和取消；下载完成后留待用户选择收录或保存到系统文件。
- Rust 检查内容而非仅依赖扩展名，计算 BLAKE3；ZIP 先验证全部路径和资源限制，再提取
  字体候选。字体内容分析、重复检测、原生预览与收录复用已有服务。
- 来源资料按字体指纹存储。WebDAV v1 追加可选 `source_metadata`，旧 `online_origin`
  继续保留；网站配置、Cookie、浏览历史、账号与临时下载 URL 不进入同步。

## 执行边界

共享 `folio-transfer` 管理任务状态与校验；平台负责系统后台调度和凭据。任务重试增加
generation，旧尝试的进度、完成、失败或系统停止回调不能覆盖新尝试。SQLite revision
用于更新冲突检查；Rust 下载还使用文件资源锁排除同一任务的并行写入。

Android 下载逐跳验证 HTTPS、解析目标地址并固定 DNS，跨源重定向不转发网页凭据。
可用强 ETag 时用 Range 和 If-Range 续传；服务端返回完整内容时重新下载。
iOS 后台会话由系统处理重定向与恢复，应用检查起始和最终 URL，不承诺逐跳 DNS/IP
拦截。暂停或失败时若系统提供恢复数据，重试优先使用该数据。

本批仅处理 HTTPS GET 下载。依赖 POST、blob、验证码或特殊客户端的下载须在网页
内重新取得受支持的链接，不重放网页脚本，也不自动尝试破解登录或下载限制。

字体限 512 MiB，ZIP 限 2 GiB；解压总量 2 GiB、单条目 512 MiB、条目数 10,000、
路径深度 16、压缩比 200。拒绝越界路径、特殊文件和加密压缩包，不递归解压嵌套包。
下载完成不自动收录；ZIP 中未选字体不进入字体库。

图标支持 PNG、JPEG、WebP、ICO，统一解码为不超过 128 × 128 的 PNG，移除原始图片
元数据。自定义文件限 8 MiB、4096 × 4096，远端文件限 1 MiB。SVG、HTML 和脚本
不会作为图标执行或保存。远端请求不携带 Cookie，逐跳检查 HTTPS 和解析地址。
成功缓存保留一天，失败请求退避十分钟；自定义图标不受自动刷新覆盖。
