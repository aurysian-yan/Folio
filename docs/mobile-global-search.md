# 移动端全局搜索

底部搜索入口打开独立全局搜索页，覆盖本地字体、当前云端目录、已启用的在线来源与设置。
输入防抖 200 毫秒；空查询展示最近搜索，不查询字体。搜索页不可见或被详情遮挡时取消查询，
旧响应不得覆盖新结果。最近搜索仅在提交或打开结果时记录，最多十项，保存在本机。

## 范围与计数

- 全部按本地、云端、在线、设置分组，每组预览三项，超过三项显示「查看全部」。
- 本地按字体家族计数，云端按文件计数，不将在线搜索动作计为字体结果，也不合并异类总数。
- 本地范围分页每次 40 项，完整保留收藏夹、智能收藏夹、位置与特征筛选；全部范围始终使用
  全部本地字体，不继承本地范围的筛选。切换范围分别保留滚动位置与已加载窗口。
- 云端只过滤共享同步状态中的显示名与文件名，不发起网络检索，不包含最近删除文件。
- 在线区展示全部启用来源的搜索动作，名称和域名匹配仅影响优先级。只有点击后才打开 WebView，
  不请求、抓取或解析远端搜索结果。
- 设置使用当前语言的标题及静态关键词索引，具体控件结果进入对应设置页并滚动定位。

## 导航与状态

本地结果打开字体详情，返回后恢复查询与位置。云端唯一匹配打开字体详情，多个匹配提供选择，
无本地匹配显示文件信息及明确下载操作；不自动切到字体库，不自动下载或自动打开下载完成的字体。
在线动作通过一次性请求传递来源和关键词，原搜索状态保留，切回搜索即可恢复。

未连接云端、凭据失效、读取失败与无匹配分别展示。一个结果源失败不覆盖其他结果源。
来源列表共用快照，来源配置保存后刷新；搜索不创建下载或来源轮询。
