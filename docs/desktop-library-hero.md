# 桌面端顶部 Hero

对应 [Figma Hero 组件组](https://www.figma.com/design/nCaYeYhwKuWx2gDYf8hq2u/Folio?node-id=8-7166)。React 组件位于 `apps/desktop-ui/src/components/LibraryHero.tsx`，React 与 React Native 共用 `shared/library-hero.ts` 的状态判断。各平台分类与同步口径见 [字体分类说明](font-classification.md)。

## 布局与状态

桌面组件基准宽度为 946px，内边距 10px，内容区最大宽度为 648px。标题和副标题均为 24px、32px 行高，云同步说明为 13px。默认高度 124px，冲突与容量状态增加一行本地统计。七种状态保留设计稿与 SwiftUI 的状态色，图标使用 Phosphor Icons。

容器宽度不超过 480px 时，参考 [308px 窄版设计](https://www.figma.com/design/nCaYeYhwKuWx2gDYf8hq2u/Folio?node-id=18-16601) 的结构：32px 图标独立置顶，左右留白为 12px，标题和副标题保持 24px、32px 行高，云同步说明保持 13px。正常状态的「随时可用」另起一行，统计与同步文字自然换行。使用组件自身的容器查询，侧栏展开或拖动后即使窗口很宽也能正确切换。排序入口位于独立一行，避免覆盖标题，未连接时底部显示「未连接云端」。

| 状态 | 数据依据 | 操作入口 |
| --- | --- | --- |
| 正常 | 全库字族、可变字族及最近访问快照 | 无标题操作 |
| 字体损坏 | `health.damagedFiles` | 字体健康 |
| 发现更新 | 调用方提供的 `updateCount` | 字体版本 |
| 云端领先 | 待下载队列，或仅云端字体 | 云端字体 |
| 本地待同步 | 托管库中尚无已发布云端记录的文件，或未完成的上传队列 | 云同步设置 |
| 云端空间不足 | WebDAV 空间不足错误；或调用方提供的容量结果 | 云同步设置 |
| 字体冲突 | 本地元数据冲突，或字体同步冲突 | 字体健康或云同步设置 |

优先级为损坏、冲突、空间不足、更新、云端待下载、本地待上传、正常。本地冲突与云端冲突独立计数，收藏夹冲突只在同步说明中提示。仅云端字体显示「可下载」，不把用户主动保留在云端的字体称为新增或待下载任务。本机字体统计使用字族口径，同步差异按文件指纹去重；最近访问不称为最近加入。仅本地和仅云端同时存在时，同步说明分别列出两侧数量。

云同步说明独立支持读取中、读取失败、未连接、已连接、待处理、同步中、已同步及同步失败。仅成功完成、已核对存放位置且没有未同步文件或冲突时显示「云字体库已同步」，同步状态读取失败不解释为未连接。减少动态效果时禁用旋转。

## 数据边界

现有桌面 API 未提供在线字体更新数量与 WebDAV 剩余配额，主窗口不生成这些数值。更新样式和容量说明保留显式数据入口，预览页使用样例验证这两种状态。实际空间不足由现有 WebDAV 错误触发。可变字族数量新增于 Tauri 快照，在完整目录中统计，避免使用当前已加载的列表页推算。

## 预览与验证

使用 `pnpm --filter @folio/desktop-ui dev`，打开 `/hero-preview.html` 可查看七个组件，并切换 946px、480px、308px 宽度、浅色/深色、中文/英文及同步状态。此 HTML 是开发预览入口，默认生产构建仅打包应用入口。

验证执行前端类型检查、Lint、测试与构建，并运行对应的 Tauri Cargo 检查。状态测试覆盖数据口径、优先级、队列去重、冲突分类以及同步失败。
